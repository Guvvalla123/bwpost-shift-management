  PART 1: CRITICAL BUGS — CODE BUGS FIXED / DEPLOY CONFIG PENDING
===============================================================================

FIXED (code bugs):

B4. ObjectId .includes() comparison (managerController.js)
    - markCheckIn used .includes() to check acceptedEmployees
    - .includes() uses strict equality; ObjectId !== String → always false
    - Fixed: .some(id => id.toString() === employeeId)

B5. Reports fill-rate capacity calculation (Reports.jsx)
    - Was: totalSlots = slotsAvailable (remaining only)
    - Now: totalCapacity = slotsAvailable + acceptedEmployees.length
    - fillRate now divides filledSlots by totalCapacity
    - Dashboard aggregation was already correct from Part 3

B6. Refresh token cookie/JWT expiry mismatch (.env)
    - Was: cookie maxAge = 7 days, REFRESH_TOKEN_EXPIRES_IN = 1d
    - Now: REFRESH_TOKEN_EXPIRES_IN = 7d (matches cookie)
    - Users no longer silently lose sessions after 1 day

B7. Google Calendar events fetched but never displayed (Calender.jsx)
    - Was: events={shiftEvents} — only app shifts shown
    - Now: events={[...shiftEvents, ...events]} — both Google + shifts
    - Added Google Calendar legend entry in sidebar

B8. Employee table Actions column commented out (ShiftRow.jsx)
    - Uncommented View / Edit / Delete action buttons
    - EmployeeTable.jsx already had "Actions" header + props

B9. Export Report button had no onClick handler (Reports.jsx)
    - Added exportCSV() function that generates a CSV file
    - Downloads: shift title, start/end times, slots, employees, status
    - File name: shift-report-YYYY-MM-DD.csv

===============================================================================
  PART 2: SECURITY VULNERABILITIES — ALL 12 FIXED
===============================================================================

S1. [CRITICAL] Attendance role check (attendanceController.js)
    - All 4 endpoints (checkIn, checkOut, startBreak, endBreak) now verify
      that if employeeId differs from req.user.id, requester must be manager
    - Prevents employees from manipulating other users' attendance

S2. [CRITICAL] Request ownership check (requestController.js)
    - approveRequest and rejectRequest now verify
      request.currentShift.createdByManager === req.user.id
    - Managers can only approve/reject requests for their own shifts

S3. [CRITICAL] Shift assignment verification (attendanceController.js)
    - checkIn now checks shift.acceptedEmployees.some() before allowing
    - No more phantom attendance records for unassigned employees

S4. [HIGH] Registration privilege escalation
    - Removed role dropdown from Register.jsx entirely
    - Backend validator (uservalidators.js) no longer accepts role field
    - Only role:"employee" is hardcoded server-side
    - Also strengthened password requirements (see S11)

S5. [HIGH] Google OAuth Client ID moved to env var (main.jsx)
    - Was: hardcoded string
    - Now: import.meta.env.VITE_GOOGLE_CLIENT_ID

S6. [HIGH] Cloudinary credentials moved to env vars
    - Settings.jsx and EmployeeProfile.jsx now read from:
      VITE_CLOUDINARY_CLOUD_NAME and VITE_CLOUDINARY_UPLOAD_PRESET
    - Added to frontend .env file

S7. [HIGH] Profile image URL validation (userController.js)
    - Added isValidImageUrl() — only allows HTTPS from res.cloudinary.com
      and images.unsplash.com
    - Blocks javascript: URIs, internal IPs, arbitrary domains
    - Also fixed inline require() calls in same file

S8. [MEDIUM] Regex injection in shift search (managerController.js)
    - Search input now escaped with replace(/[.*+?^${}()|[\]\\]/g, "\\$&")
    - Prevents ReDoS attacks

S9. [MEDIUM] Stricter auth rate limiting (userRoutes.js)
    - Login and register: max 10 attempts per 15 minutes per IP
    - Separate from global 100/15min limit

S10. [MEDIUM] CSRF protection (server.js)
     - Added origin-checking middleware on all mutation requests
     - Validates Origin header against allowedOrigins list

S11. [LOW] Password strength (uservalidators.js + Register.jsx)
     - Backend: min 8 chars, uppercase, lowercase, number, special char
     - Frontend: matching validation with clear error messages

S12. [LOW] No-origin CORS blocking (server.js)
     - In production: requests without Origin header are blocked
     - In development: still allowed for Postman/curl testing

BONUS: Morgan logger now uses "short" format in production

       - { currentShift: 1, status: 1 }

SC2. Dashboard uses MongoDB aggregation (dashboardController.js)
     - Replaced Shift.find() that loaded ALL shifts into memory
     - Now uses two $aggregate pipelines for capacity + attendance stats
     - Fixed capacity formula: totalCapacity = slotsAvailable + filled
     - Attendance now filters for status === "checked_in"

SC3. Pagination on all unbounded endpoints
     Added page + limit with skip/limit and countDocuments to:
       - getAvailableShifts (employeeController.js)
       - getMyShifts (employeeController.js)
       - getMyRequests (employeeController.js)
       - getAllEmployees (managerController.js)
       - getEmployeeAttendanceHistory (managerController.js)
       - getAllRequests (requestController.js)
     All return { total, page, pages } metadata

SC4. Race conditions fixed with atomic operations
     - applyForShift: now uses Shift.findOneAndUpdate with conditions
       { slotsAvailable: { $gt: 0 }, acceptedEmployees: { $ne: id } }
       + $push + $inc — no more overbooking
     - assignEmployeeToShift: same atomic pattern applied

SC5. Graceful shutdown + DB reconnection
     server.js:
       - Added SIGTERM/SIGINT handlers
       - Closes HTTP server, then MongoDB connection, then exits
       - 10s timeout fallback
     config/db.js:
       - Retries connection up to 5 times with 3s delays
       - Logs disconnected/error events

SC6. React.lazy() code splitting (App.jsx)
     - All 13 page components lazy-loaded with React.lazy()
     - Employee never downloads manager code and vice versa
     - Added PageLoader spinner as Suspense fallback

SC7. Debounced search inputs
     - Created src/hooks/useDebounce.js (300ms delay)
     - Applied to: ManagerShifts.jsx, Employee.jsx,
       ShiftRequest.jsx, MyRequests.jsx

SC8. LiveClock optimized
     - Wrapped in React.memo in both Dashboard.jsx and EmployeeDashboard.jsx
     - Changed interval from 1s to 60s (only shows hours:minutes)
